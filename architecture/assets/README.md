## Visual source of truth

The editable design master lives in the private NCMA V4 Figma **Architecture Atlas** page. Components inherit the existing V4 visual tokens: dark surfaces, muted signal teal, controlled amber for human authority, Inter and IBM Plex Mono. The Raven mark is an editorial treatment of the original brand illustration already embedded in that Figma file; the source raster is not separately published here.

The SVGs preserve searchable/selectable text in most browsers; font substitution can occur when Inter or IBM Plex Mono is unavailable. Each figure remains a **logical summary**, while its accompanying Markdown/Mermaid document preserves more specific decision paths, exceptions and limitations.

## Safety and truth boundary

- Figures deliberately omit real network topology, hosts, private ports, account IDs, tunnel/access configuration, privileged MCP catalogs and production secrets.
- No private code, screenshots of internal systems, training corpora, private UI asset pack or historical image-source folders were copied.
- A diagram arrow is not evidence of an accepted deployed integration.
- `VERIFIED`, `PASS` and human approval refer only to explicitly bounded predicates and gates.
- Web Research V1 accepted source-grounded synthesis was still pending at its published checkpoint.
- Knowledge retrieval supports evidence discovery/ranking; domain correctness belongs to deterministic domain authority.

Before replacing any figure, update the Figma master, review the generated SVG as source text and visually, run the [architecture publication review](../PUBLICATION_REVIEW.md), and retain the Mermaid reference. Do not edit the exported SVG by hand and then claim Figma remains the visual source of truth.
